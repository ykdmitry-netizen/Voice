# Pantela Voice для Windows

Локальная голосовая диктовка для Windows по мотивам
[PantelaVoice](https://github.com/EvgenyPantela/PantelaVoice) (SwiftUI, macOS).
Без аккаунта, подписки и облака: звук уходит только в локальную модель на вашем
компьютере.

Сделано под конкретную машину — **Intel Core i5-4460, 4 ядра, 8 ГБ RAM, без
пригодного GPU** — поэтому движок по умолчанию не Whisper large-v3-turbo, а
**Parakeet TDT 0.6B v3 (int8)**: он и быстрее, и точнее на этом процессоре.
Замеры — в [bench/REPORT.md](bench/REPORT.md).

## Как пользоваться

1. Запустить **`PantelaVoice.bat`** (двойной клик). В трее появится значок
   микрофона. Если значок не появился, откроется маленькое окно управления —
   кнопки «Начать диктовку / Настройки / Выход».
2. Поставить курсор в любое текстовое поле.
3. Зажать **Ctrl + Alt + Пробел**, сказать фразу, отпустить клавиши.
4. Через ~1 секунду текст сам вставится в поле (Ctrl+V), а также останется в
   буфере обмена.

Панель внизу экрана показывает состояние: «Запись…» с уровнем микрофона,
«Распознаю…», «Готово». **Esc** во время диктовки отменяет её.
Пока идёт запись, комбинация Ctrl+Alt+Пробел не попадает в приложения, так что
в текст не вставится лишний пробел.

## Первый запуск

Модель Parakeet (670 МБ) уже лежит в `models/parakeet-tdt-0.6b-v3-int8`, если вы
получили папку целиком. Если файлов нет — первый запуск скачает их сам, либо
откройте «Настройки → Распознавание → Скачать модель». После загрузки интернет
не нужен вообще.

Модель загружается в память ~6 секунд при старте приложения, дальше диктовка
работает мгновенно.

## Настройки

**Распознавание**

| Движок | Когда выбирать |
|---|---|
| Parakeet TDT 0.6B v3 | по умолчанию: ~1 с задержки, русский + английский + ещё 23 языка, пунктуация и заглавные буквы |
| GigaAM v2 (русский) | только русский, текст без пунктуации и заглавных букв |
| Whisper (faster-whisper) | как запасной вариант; на этом CPU пригодны только `base` и `small`, `medium` и `large-v3-turbo` дают меньше реального времени |

**Управление** — горячая клавиша (кнопка «Записать» ловит нажатие), режим
«удерживать» или «нажать-отпустить», микрофон, панель состояния, звуковой
сигнал, автозапуск при входе в Windows.

**Вставка** — доставлять текст в активное окно, способ доставки:
**Ctrl+V** (быстро, по умолчанию) или **посимвольная печать** (медленнее, но
работает там, где Ctrl+V игнорируется). Плюс копирование в буфер и возврат
прежнего содержимого буфера после вставки.

**Словарь замен** — по одной замене в строке, `что=на_что`. Полезно для имён,
терминов и латиницы: `паракейт=Parakeet`.

Настройки лежат в `%APPDATA%\PantelaVoice\settings.json`, журнал — рядом,
в `pantela.log`.

## Установка на новой машине

В репозитории лежит только код: библиотеки (`pylibs`), модели (`models`) и
кэши в него не попадают — это сотни мегабайт, а файл модели Parakeet весит
652 МБ и в GitHub не влезает.

Нужен **Python 3.12 x64**. Дальше один запуск:

```bat
setup_env.bat
```

Скрипт скачает библиотеки, распакует их в `pylibs`, скачает модель Parakeet
(около 670 МБ) и прогонит самопроверку. После этого — `PantelaVoice.bat`.

Вручную то же самое:

```powershell
py -3.12 bench\fetch_deps.py faster-whisper sherpa-onnx sounddevice pystray pillow
py -3.12 bench\unpack_wheels.py
py -3.12 bench\download_models.py parakeet
```

Список версий — в `requirements.txt`. Если pip в системе работает нормально,
можно и привычным способом: `py -3.12 -m pip install --target pylibs -r requirements.txt`,
а затем всё равно вызвать `bench\unpack_wheels.py` — он кладёт в `pylibs`
патч `tools/sitecustomize.py` (нужен там, где каталоги с правами `0o700`
недоступны для записи; на обычной машине безвреден).

Модель можно не качать заранее: приложение предложит это сделать в настройках,
и после загрузки интернет ему не нужен.

## Из чего собрано

- Python 3.12 + библиотеки в `pylibs` (sherpa-onnx, onnxruntime, faster-whisper,
  CTranslate2, sounddevice, pystray, Pillow). Ничего ставить в систему не нужно.
- Распознавание: sherpa-onnx (Parakeet/GigaAM, ONNX int8) и CTranslate2 (Whisper).
- Горячая клавиша: низкоуровневый хук клавиатуры Windows (`WH_KEYBOARD_LL`).
- Вставка: буфер обмена + `SendInput` (Ctrl+V).
- Интерфейс: tkinter (панель состояния, настройки) + pystray (трей).

## Если что-то не работает

- **Значка в трее нет.** Открывается резервное окно управления. Проверьте
  `pantela.log`; трей можно отключить переменной `PANTELA_NO_TRAY=1`.
- **Текст не появляется в поле.** Переключите «Вставка → Способ → печатать
  посимвольно»: некоторые приложения не принимают синтезированный Ctrl+V.
  Текст в любом случае остаётся в буфере обмена — можно вставить вручную.
- **Микрофон молчит.** «Настройки → Управление → Проверить микрофон и модель»
  запишет 3 секунды и покажет уровень и результат.
- **Хук клавиатуры не встал.** Так бывает, если другое приложение уже
  перехватывает эту комбинацию (например, драйвер видеокарты или мессенджер).
  Смените комбинацию в настройках.

## Разработка и проверки

Все проверки — в `bench/`. Запуск (путь подставьте свой):

```powershell
$env:PYTHONPATH = "D:\...\pantela-win\pylibs"
$env:PANTELA_HOME = "D:\...\pantela-win\testhome"

py -3.12 bench\selftest.py          # 12 проверок узлов
py -3.12 bench\hotkey_test.py       # логика хука + цепочка «нажал-сказал-отпустил»
py -3.12 bench\integration_test.py  # сквозной путь до буфера обмена
py -3.12 bench\paste_test.py        # доставка текста в настоящее поле Win32
py -3.12 bench\mic_test.py          # реальный захват с микрофона
py -3.12 run_pantela.pyw --verbose --quit-after 10   # запуск и авто-выход
```

`paste_test.py` отправляет настоящие нажатия клавиш, поэтому **запускайте его
только когда готовы отдать ему рабочий стол**: он сам проверит, что активное
окно — его собственное, и при чужом фокусе ничего не отправит.

Что автоматические проверки **не** покрывают (нужен живой пользователь):
доставка реального нажатия клавиатуры через систему и появление значка в трее
на обычном рабочем столе. Внутри песочницы агента синтезированный ввод доходит
до системы только когда активно собственное окно процесса, а значок в трее не
отображается — поэтому включается резервное окно управления. Логика хука при
этом проверяется целиком: `hotkey_test.py` скармливает хуку синтетические
события клавиатуры.

`PantelaVoice-debug.bat` запускает приложение с консолью — видно журнал.
